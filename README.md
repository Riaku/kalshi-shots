# Who asks for shots first? — a fake prediction market

A joke clone of a Kalshi event page for a group of friends. One static HTML file,
no backend, no build step, no data collection. Every price, chart, order book and
trade on the page is generated in the browser from a seeded random walk.

Markets:

- **Who asks for shots first?** — Sessu, Jay, Axel, Carcar, Alazel, Fisk
- **Who's gonna show up last?** — same six people, different prices

Prices across the six outcomes always sum to 100¢, the way a real multi-outcome
market would. The chart is a Brownian bridge anchored at both ends, so the 24h
change in the header actually matches the 1D chart.

## Run it

Open `index.html`. That's it.
